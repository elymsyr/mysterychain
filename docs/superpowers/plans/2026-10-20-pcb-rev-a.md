# PCB rev A (KiCad) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A KiCad 9 project for the MysteryChain PCB rev A. ERC and DRC clean, with a fab pack: Gerbers, drill, BOM with TR sources, pick-and-place, assembly PDF, 1:1 check print and STEP. Everything is regenerated from one Python parts list.

**Architecture:**
- `electronics/pcb/parts.py` is the single source: parts, pin → net, placement and BOM data.
- `gen_lib.py` makes the custom footprints and the E73 symbol.
- `gen_sch.py` writes the schematic: symbols on a grid, a net label on every pin.
- `gen_pcb.py` builds the placed board with pcbnew. `route.py` autoroutes it with Freerouting.
- `check.py` holds every assertion. `fab.py` exports the fab pack.
- `build.sh` runs the chain.

Firmware (board package, bootloader, self-test) and case v8 are separate follow-up plans. Firmware needs only the spec's pin map; case v8 needs this plan's STEP and final positions.

**Tech Stack:**
- KiCad 9.0.9: `pcbnew` Python in `/usr/bin/python3`, plus `kicad-cli`.
- Freerouting 1.9.0 (Java 17 is installed).
- build123d in `~/.venvs/cad`, used only for the E73 3D box.
- Stdlib Python, nothing else installed.

**Spec:** [docs/superpowers/specs/2026-10-20-pcb-design.md](../specs/2026-10-20-pcb-design.md). It was amended 2026-10-20 while this plan was written; the owner reviews the amendments together with this plan:
- parts on both sides;
- outline r 18.0;
- GND under the E73;
- SW1/SW2/SW3 case notes;
- IMU axes.

## Global Constraints

- **Project:**
  - Files live in `electronics/pcb/`, project name `mysterychain` (`.kicad_pro/.kicad_sch/.kicad_pcb`).
  - Custom library prefix `mysterychain:`.
  - Generated files are not hand-edited before rev A freeze; `build.sh` must reproduce them.
- **Board:**
  - 2 layers, 1.0 mm FR-4, 1 oz copper. F = front (display side), B = back (midframe side).
  - **Back:** E73, J1, SW1, SW2, SW3, C 100 µF 1206, D1, D2.
  - **Front:** every other part, each ≤ 1.2 mm tall, plus all test and wire pads.
  - Back parts ≤ 3.4 mm tall (4.51 layer − 1.0 board − 0.1).
- **Coordinates:**
  - KiCad x = case X, KiCad y = −case Y. The case origin (display center) sits at KiCad (100, 100) mm, with the grid and drill origin there. KiCad's top view = looking at the front.
  - `parts.py` stores case coordinates; `gen_pcb.py` converts them.
- **DRC rules** (TR-safe defaults; Task 1 may only loosen them to the chosen fab's published limits):
  - track ≥ 0.20, clearance ≥ 0.20;
  - via drill 0.40 / Ø 0.80;
  - copper-to-edge 0.30, hole-to-hole 0.50;
  - silk width ≥ 0.15;
  - default track 0.25. No power net class: the biggest net current is about 100 mA.
- **Outline:**
  - circle r 18.0 cut at Y ≤ +7.0;
  - J1 tongue (about X ±5.6) out to J1's board-edge line, J1 face at Y −18.2;
  - Ø3.0 notches at r 17.6, angles 205° and 335°.
- **Pin map:** the spec table, verbatim. E73 nets only on castellated pads, except inner pad 24 = GND (harmless, helps a later reflow).
- **Process:**
  - No commits unless the owner asks.
  - Docs in English, diagrams in mermaid.
  - No order is placed with a fab or shop without the owner.

## Review Focus

1. **A back-side part mirrored wrong.** The board is dead: E73 pads swapped, or J1 facing inward. Pinned by `test_backside_orientation` in Task 4.
2. **The TR part's pinout ≠ the KiCad footprint.** Examples: SOT-23 pin order, USB-C variant, switch pins, IMU pin 1. Pinned by `test_critical_pins` (Task 3), plus the 1:1 print laid with the real parts (Task 6).
3. **A part hits the case.**
   - Front part > 1.2 mm.
   - J1 face off Y −18.2.
   - Copper beyond r 18.0 outside the tongue.
   - A part in a leg notch.

   Pinned by `test_case_fit` (Task 4).
4. **The antenna keep-out gets copper.** The cause can be a pour, a test pad or an autorouted track. Pinned by `test_antenna_clear` (Task 5).
5. **5 V or the raw battery reaches a GPIO.** The risky spots are the STAT divider, a wrong pin and VSYS. Pinned by `test_no_high_voltage_on_gpio` (Task 3).
