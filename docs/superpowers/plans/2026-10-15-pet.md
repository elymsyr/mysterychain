# Cat pet (O2, K1–K7, S1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the cat scene into a pet with stats, day/night, mood animations, steps, petting, a runner game and app settings, all surviving power-off.

**Architecture:** Stats and rules live in a new plain C++ header `pet.h`; the cat scene (`cat.h`) includes it, gains a tinted palette, new states and a visitor, and includes the runner `game.h` inside `namespace kitty`. `firmware.ino` wires flash storage, button gestures, IMU pedometer/tap, protocol and motor inside `#ifdef SCENE_PET`, so the other three scenes build unchanged. The Flutter app parses the new board lines and adds stats, Feed and a settings screen.

**Tech Stack:** Arduino (Seeed nRF52 core 1.1.13, Bluefruit, Adafruit LittleFS / InternalFileSystem, Seeed LSM6DS3), g++ for PC checks, Python + Pillow for frame sheets, Flutter + flutter_blue_plus.

**Spec:** [docs/superpowers/specs/2026-10-15-pet-design.md](../specs/2026-10-15-pet-design.md)

## Global Constraints

- Cat scene only; `pavi.h`, `nausicaa.h`, `teto.h` must still compile.
- Animation rules: motion uses `dt`; nothing new enters the bubble band (y 11–24) except the existing moon position when the clock is unknown.
- Board is the source of truth for settings; unknown `#` commands still show as text.
- Motor quiet when `vib = 0` or inside the night window; find always buzzes.
- No commits (owner's instruction for this run).
- Project docs in English, diagrams in mermaid.

## Review Focus

1. Power-off before the saved file is loaded (setup's "tap goes back off" path) must not overwrite `/pet` with defaults.
2. Clock unknown for a whole session, then power-off: the next sync must still apply the offline time (save `bootSaved + uptime` when the clock is unknown).
3. Holding the button past 3 s inside the game leaves the game and must not power off while still held.
4. Motor buzz and button clicks must not register as IMU double taps (motor mask + button guard).
5. Bubble band text in the game must not jitter when it scrolls (scroll clock = game time, not score changes).

### Task 4: Runner game (K7)

**Files:** Create `interfaces/watch/firmware/game.h` (included at the end of `cat.h`, inside `namespace kitty`); extend `interfaces/watch/test/pet_test.cpp`.

**Interfaces:** `struct Game { bool on, dead, ended, newBest; int score; float t, speed, dist; … } game`; `void gameStart()`, `void gameInput(bool held)` (edge = jump), `void gameStop()`, `void gameLabel(char *out, int cap)`; `game.ended` is an event the firmware clears.

- Physics: G 200 px/s², take-off 65 px/s; while held, no gravity from 0.10 s to 0.35 s. Pot 6 px tall, fence 15 px, bird just above the standing head (score ≥ 20). Ground hitbox x [cat.x−2, cat.x+4], head hitbox x [cat.x+1, cat.x+12].
- Speed 40 px/s + 5 per 10 points, cap 90. Gap = speed × (1.1 + 1.2 rnd) + 10 px.
- Dead: cat `KO`, `pet::gameOver(score)`; 10 s without a press → `on = false`.
- [ ] Test: a 100 ms tap clears a pot and not a fence at 40 and 90 px/s; a 300 ms hold clears a fence; any jump hits a bird, standing does not.
- [ ] Frame sheet: running, jumping a pot, held jump over a fence, bird, game over.

### Task 5: Firmware glue (O2, S1, K1–K4, K7)

**Files:** Modify `interfaces/watch/firmware/firmware.ino` (include `cat.h`).

- Storage: `InternalFS` file `/pet`, `load()` in setup before BLE, `save()` every 10 min + feed + settings + new best + `powerOff()` (only after `load()`).
- `buzz(n, on, per)` gates the motor (vib, night) except find; purr = 5 × 40 ms / 160 ms.
- Button: press edge → `button N` + buzz; release < 1 s → tap (300 ms wait; second press = double → feed); 1 s buzz; release 1–3 s → game; 3 s → power off, or leave the game (consumed until release). In game: level → `gameInput`, press after 1 s dead → restart.
- IMU: pedometer on (`CTRL10_C |= 0x14`), read every 2 s, 16-bit wrap; double tap (`TAP_CFG 0x8F`, `TAP_THS_6D = TAP_THS`, `INT_DUR2 0x7F`, `WAKE_UP_THS 0x80`, `MD1_CFG 0x08`), `TAP_SRC` bit 4; shake decided 300 ms late, double tap inside → purr.
- Protocol: `#feed`, `#stats`, `#set vib|shake|night|name`; replies `stats`, `settings`, `fed`/`full`, `game`.
- Once a second: tick, mood → scene; once a minute: tint + palette rebuild, `stats` if changed.
- [ ] `arduino-cli compile` for cat, pavi, nausicaa, teto.
